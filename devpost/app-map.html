⚡ awam Architecture & App Map

A developer-first CLI for proactive edge case detection and unit test generation.

What awam Does

awam runs right where you code: in your terminal. Instead of passive test generation that bypasses your learning, awam acts as an active testing coach: it inspects your source code and local dependencies, presents critical edge cases as Socratic inquiries ("What happens to Y when X fails?"), and offers optional test generation (--generate) and live validation (--run).

Code Tour Route (3 Core Stops)

1. The Orchestrator & CLI Entrypoint

awam/cli.py → main()

Defines Click command options (--generate, --run, --mock, --audit-only). Manages the pipeline without coupling: pre-flight checks, dependency resolution, engine invocation, and test runner subprocess execution.

2. Socratic Edge Case Engine

awam/engine.py → analyze_code(), EdgeCaseAuditItem

Uses Pydantic structured output with google-genai to return candidate edge cases, positive reinforcement for covered tests, and probing Socratic inquiry questions. Includes built-in automatic retries for demand spikes and simulation fallback via --mock.

3. Test Runner & Fix Advisor

awam/runner.py → execute_pytest(), suggest_fix()

Executes pytest via subprocess.run. When an unhandled error path fails, it extracts the trace and prompts Gemini Flash for a 2-sentence fix recommendation advising the developer where to place an error guard.

To Change This, Start Here

Tweak Inquiry Prompts

Modify the prompt instructions and EdgeCaseAuditItem schema in awam/engine.py.

Customize Terminal Theme

Update color styles and table column layouts in awam/reporter.py.

Adjust Test File Patterns

Edit path resolving and AST name parsing in awam/test_manager.py.

A Practice to Reuse

Pairing Pre-Flight AST Checks with Structured AI Schemas:
Instead of sending raw unverified source code to an LLM, awam runs a lightweight local Python AST check (ast.parse) first. If the code has a broken syntax error, it fails immediately with an exact line number in 0.02 seconds for $0 cost. Once verified, it calls Gemini with a strict Pydantic JSON schema (AnalysisResponse), ensuring reliable, typed data structures.

Reuse this pattern whenever building developer tools: fail fast locally, then enforce strict schemas over network calls.

How to Run awam

# Safe inquiry mode (default, non-destructive)
awam sample/calculator.py --mock

# Write / append missing tests into tests/
awam sample/calculator.py --generate --mock

# Validate tests with pytest and get fix guidance
awam sample/calculator.py --run --mock

# Use live Gemini 3.1 Flash Lite model
export GEMINI_API_KEY="your-api-key"
awam sample/calculator.py
